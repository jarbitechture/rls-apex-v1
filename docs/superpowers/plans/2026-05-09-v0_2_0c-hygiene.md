- [ ] **Step 2: Pick the new default**

Use `Path.home() / ".rls-apex" / "feedback.jsonl"`. Rationale:
- Persistent across reboots (not `/tmp/`, which macOS clears)
- User-scoped (no root permissions needed)
- Existing convention: `~/.rls-apex/` is a sensible private namespace; the gateway already creates parent dirs on first write
- Operating Rule #14 satisfied (no `/tmp/`)

- [ ] **Step 3: Edit the default**

Replace line 672:

```python
# OLD

    os.environ.get(
        "FEEDBACK_LOG",
        # Operating Rule #14: never default to /tmp/. ~/.rls-apex/ is created on

        str(Path.home() / ".rls-apex" / "feedback.jsonl"),
```
